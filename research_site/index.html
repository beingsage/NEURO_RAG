Research Summary

This website presents the spiking multimodal memory model from spiking_multimodal_memory.ipynb as a living research page. It explains the algorithmic stages, visualizes the architecture, and simulates representative experiments from the notebook.

Core contributions:
  • Multimodal encoding of structured SQL, graph, and text inputs
  • Novelty-driven entorhinal gating and sparse pattern separation in DG
  • Recurrent attractor dynamics in CA3 with STDP and consolidation
  • CA1 rate-based readout for reconstruction, cross-modal completion, and relation decoding

Algorithm Pipeline

1. Encoders

SQL, graph, and optional text inputs are converted into spiking activity. Numeric fields use population rate codes, graph relations use temporal delay codes, and text uses semantic phase-of-firing bursts.

2. Entorhinal Cortex (EC)

EC computes a novelty energy estimate for the current multimodal input stream and determines neuromodulatory gain. Novel episodes receive stronger plasticity through a higher modulation state.

3. Dentate Gyrus (DG)

DG maps the entorhinal representation to a sparse code using random projection and k-WTA. This pattern separates episodes before they reach the associative CA3 attractor.

4. CA3 Attractor

CA3 is a recurrent spiking network with excitatory and inhibitory neurons. Feedforward input, delayed synaptic currents, and STDP form attractor assemblies for memory traces.

5. CA1 Readout

CA1 decodes CA3 activity back into the encoder space. It supports SQL reconstruction, graph structure recovery, optional text reconstruction, and relation classification.

6. Memory Dynamics

Encoding is two-stage: fast pre-activation followed by plasticity and optional consolidation replay. Retrieval uses partial cues to complete stored patterns through CA3 dynamics.

Simulation Stages

Stage 1: Pre-activation

The encoded multimodal spike stream is injected into CA3 with plasticity disabled. This initial pass detects familiarity and prepares the attractor basin.

Stage 2: Plasticity

Plasticity is enabled using an STDP-modulated gain. Novel patterns receive boosted learning, while familiar patterns are stabilized. CA3 assemblies are reinforced through recurrent weight updates.

Consolidation Replay

The model optionally replays the learned pattern with plasticity disabled. This stabilizes the engram and improves retention across later episodes.

Run and Update

To regenerate the simulation data, run the Python script from the repository root:

python generate_research_site_data.py

Then open research_site/index.html in a browser. If the browser blocks local script loading, use a lightweight file server:

python -m http.server --directory research_site 8000

Open http://localhost:8000.
